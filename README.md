# WorkFlow AI — Workplace Productivity Assistant

A single, integrated dashboard that helps professionals automate everyday workplace tasks using AI-powered tools.

## Overview

This project was built for the ASA Online Week 16 assignment using Lovable AI. Rather than building separate applications, it's one platform with a shared design system and sidebar navigation containing three connected AI-powered productivity features.

## Features

- **Smart Email Generator** — generates professional workplace emails from recipient, purpose, key points, tone, and length, with editable output, copy, regenerate, and clear controls
- **Meeting Notes Summariser** — turns meeting notes into a structured summary, key decisions, action items (with responsible person and deadline where mentioned), deadlines, and important points
- **AI Task Planner** — takes multiple tasks and generates a prioritised (High/Medium/Low) daily or weekly schedule, with reasoning for the prioritisation

All AI outputs are editable before use, and the app includes a Responsible AI disclaimer and a dedicated About/Responsible AI page.

## Tools Used

- Built using Lovable AI
- Hosted via Lovable and connected to GitHub

## Responsible AI Note

AI-generated content may contain errors or omissions. All outputs are editable so they can be reviewed and verified before use in real workplace communication or decisions.
